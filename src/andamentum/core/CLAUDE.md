# andamentum.core — notes for Claude

Moved from the root `CLAUDE.md`, word for word. Claude Code loads this file when it reads files in this directory.

## Overview

- `andamentum.core` — shared model-resolution, `AgentRunner`, and embedding infrastructure (`core.embeddings`) used by all sub-modules

## Decision models (`core.decisions`)

A package, local Ollama only: `POST /v1/systemone` (Ollama 0.35+, Jev-style decision models; the wire shape is confined to `Question.wire`, `build_body`, `parse_answers` in `api.py`). One request puts 1-64 named questions about one `state` (64 KiB body limit, over-length input is HTTP 400, never truncated). Types: `noul` (probability a condition holds, `Answer.p_true`), `choice` (probabilities over described options; `options` is `{option: description}` or a list), `score` (weak, 50-55% in the vendor numbers: do not decide on it). Notes on the real endpoint: `noul` answers carry only `{noul: p}`, so `confidence = max(p, 1-p)` is derived and is concentration, not correctness.

- **Layout.** `errors.py` (one base `DecisionError`: `DecisionModelUnavailable`, `DecisionRequestTooLarge`, `DecisionRequestRejected`, `DecisionResponseError`), `api.py` (Question, Answer, limits, wire, usage; no I/O), `model.py` (`DecisionModel`, `decide`, `model_digest`), `cli.py` (`python -m andamentum.core.decisions`), `testing.py` (`StubDecisions`, an `httpx.MockTransport` Ollama for offline tests).
- **`DecisionModel`** mirrors `make_ollama_embedder`: a long-lived handle (`name` as `ollama:<name>` or `<name>`, explicit `base_url` defaulting to `DEFAULT_OLLAMA_URL`, one `httpx.AsyncClient`, `timeout`, `load_timeout` for the first request). `await DecisionModel.open(name)` checks `/api/version` >= 0.35, the model exists (`/api/show`, with the `ollama pull` fix in the message), its `capabilities` include `decision` (absent field: accepted with a warning), and reads the digest from `/api/tags` (`/api/show` carries none). **Every request to one server is serialised by one lock** shared by all handles in the event loop; never gather local calls. `decide`, `decide_with_usage`, `decide_many` (one request per state, sequential), `ask_all` (chunked at 64 questions and 64 KiB). Token usage totals on the handle and an optional `log(event)` callback gets one record per request.
- **How a site uses it.** A site takes a keyword-only `decision_model` (CLI `--decision-model NAME`). With one, the site asks it **instead of** its LLM call: a `choice` question gives the top choice, a `noul` question is a yes when `p_true >= 0.5`. Without one the site behaves as it always did. There are no thresholds, calibration records, labelled sets or escalation paths: a decision model is a faster, less random replacement for the LLM call, and a failure of it raises. `DecisionModel.open(name)` checks the server (0.35+), that the model is installed and has the `decision` capability, and reads its digest; every request to one server goes through one process-wide lock, and the request limits are checked before sending. `ask_all` splits more than 64 questions into several requests.
- **CLI**: `check --model nimble:9b` (server version, capability, digest, one smoke answer). Live tests use the `ollama` marker (deselected by default).
- Errors raised by the old module as raw `httpx` errors and `ValueError` are now `DecisionError` subclasses (`DecisionResponseError` and `DecisionRequestTooLarge` are also `ValueError`). One name each: `Question`, `Answer`, `DecisionModel.open`. The old names (`DecisionQuestion`, `DecisionAnswer`, `make_decision_model`) still import from `core.decisions` but are not in any `__all__` and `core` no longer re-exports them. The calibration helpers of the old module (`calibrate`, `CalibrationRecord`, `threshold_for`) were removed because nothing imports them.

## Interface notes

- **No environment configuration.** `resolve_model_from_args(model)` returns the model or raises `ValueError` (no `ANDAMENTUM_MAIN_LLM_MODEL` fallback, no `sys.exit`); `resolve_embedding_model_from_args` and its env var are gone. `ANDAMENTUM_LLM_CONCURRENCY` is gone: `llm_concurrency(model)` is 1 for a local model and 8 otherwise, and `AgentRunner(model=, concurrency=None)` takes an explicit width. `ANDAMENTUM_AUDIT_LOG` is gone: `audit_log.log_cloud_call(log_path=...)` and `is_enabled(log_path)` take the path; the log is off when it is `None`. Credentials and provider settings (`OLLAMA_BASE_URL`, AWS) stay in the environment.
- **`run_agent_with_fallback`** takes `model_settings` like `run_agent_with_usage`.
- **Errors.** `CoreError` (`core/errors.py`) is the base of `FetchGateError` (`RobotsBlocked`, `PaywallBlocked`), `SsrfBlocked`, `ResponseTooLarge` and `DecisionError`; all are exported from `andamentum.core`. core has no command.
