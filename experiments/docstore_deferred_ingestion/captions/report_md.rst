**The narrative report**, assembled by ``scripts/build_report.py`` from the
measured artefacts only — every number in it is read from a results file, none
is typed in. It carries the scoreboard, the cross-cutting observations, the
noise band, the statistical-power statement, the "what is not reproducible"
list and the four figures.

``report.html`` beside it is the same document rendered through
``andamentum-typeset --style report``.
